# recall — 과거 대화 검색

`~/.claude/projects/` 아래 대화 기록(JSONL)에서 사용자/에이전트 텍스트만 검색한다. (thinking·도구 호출 제외)

## 언제 쓰나
- 사용자가 이전 대화·작업을 언급할 때 ("지난번에 얘기한 …", "전에 했던 …")
- 이미 논의했을 법한 주제라 과거 결정·시도를 알면 중복 작업을 피할 수 있을 때

## 명령

1. 검색 (모든 단어가 같은 메시지에 있어야 함, 대소문자 무시, 최신 세션순)
```
python3 ~/.claude/skills/recall/search.py 배포
python3 ~/.claude/skills/recall/search.py 배포 롤백 --days 365 --project myproject --limit 10 --context 300
```
옵션: `--days N`(기본 90) `--project 부분문자열`(프로젝트 경로 슬러그) `--limit N`(기본 20) `--context 글자수`(기본 200)

2. 세션 맥락 읽기 (검색 결과의 세션 id, 타임스탬프 사용)
```
python3 ~/.claude/skills/recall/search.py --session <세션id> --around 2026-11-13T03:40
```
`--around` 생략 시 처음부터. 메시지당 약 1500자, 전체 약 30KB로 잘림.

## 팁
- 결과가 없으면 동의어, 한글/영문 변형, 더 짧은 단어로 다시 시도하고 `--days`를 늘린다.
- 단어를 너무 많이 넣으면 AND 조건이라 결과가 사라진다. 1~2개 핵심어부터.
- 먼저 검색으로 후보 세션을 좁힌 뒤 `--session`으로 필요한 부분만 읽는다.

## 주의
찾은 내용은 과거 시점의 기록이다. 파일·코드·설정이 이후 바뀌었을 수 있으니, 의존하기 전에 현재 상태를 확인(파일 읽기 등)할 것.
