# KakaoTalk (com.kakao.KakaoTalkMac)

AppleScript 사전이 없어 화면 조작(마지막 수단)으로만 다룬다. 손쉬운 사용 권한이 필요하고, 화면 확인에는 화면 기록 권한이 필요하다.

## 한글 입력 (검증함)
- `System Events`의 `keystroke "한글"`은 입력칸에 □(두부 글자)로 깨져 들어간다.
- 클립보드 붙여넣기(`pbcopy` + ⌘V)는 입력칸에 아무것도 넣지 못했다.
- `keystroke "dhsmf"` 같은 영문은 입력기를 거치지 않고 알파벳 그대로 들어간다.
- 됐던 방법: 한글(2벌식) 입력기가 켜진 상태에서 **물리 키 코드**를 `key code`로 하나씩 보낸다(키 사이 `delay 0.07`). 예) `오늘`=d h s m f → key code 2,4,1,46,3. 띄어쓰기는 49.
- 키 코드(QWERTY): a0 s1 d2 f3 h4 g5 z6 x7 c8 v9 b11 q12 w13 e14 r15 y16 t17 u32 i34 o31 p35 j38 k40 l37 n45 m46. 영문 자판 기준이라 자음·모음은 2벌식 배열을 따른다.

## 입력칸 지우기
- ⌘A 전체 선택은 먹지 않았다. `key code 51`(Delete)을 글자 수보다 넉넉히 반복해서 지운다. 비어 있을 때 더 눌러도 무해하다.

## 보내기
- 입력한 글자에 이모티콘 추천(파란 글자)이 붙을 수 있다. Enter 대신 **전송 버튼**을 클릭해 텍스트로 보낸다.
- 보내기 전에 입력칸을 `screencapture -R`로 찍어 내용을 확인하고, 보낸 뒤에도 대화창에서 말풍선을 확인한다.

## 창과 좌표
- 채팅 목록 창 이름은 `카카오톡`, 대화창 이름은 상대 이름이다. `나` 배지가 붙은 항목이 나와의 채팅이다.
- 목록의 접근성 요소를 `entire contents`로 훑는 방식은 60초 넘게 걸려 쓸 수 없다. 창 위치·크기(`position`/`size`)를 읽고 스크린샷 좌표(포인트 = 스크린샷 픽셀 / 2)로 클릭한다.
- 목록 항목은 더블클릭으로 대화창이 열린다. 클릭은 `CGEventCreateMouseEvent`로 보낸다(JXA).
- 사용 전 사용자가 대화 상대·내용을 정한 요청인지 확인한다. 메시지 발송은 사용자 명의 발신이다.
