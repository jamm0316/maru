# 앱별 노트

`reference/apps/<번들 ID 끝부분 또는 짧은 이름>.md` 한 앱에 파일 하나(예: `finder.md`, `safari.md`). 새 앱을 다루는 방법을 알아냈으면 같은 세션에서 덧붙이고 maru 저장소에 짧게 커밋한다.

## 담는 것 (일반적인 운영 지식만)
- 스크립트 가능 여부(사전 위치, AppleScript/JXA/CLI/URL 스킴 중 무엇이 되나)와 필요한 권한
- 가장 빠르고 확실한 방법(복사해서 쓸 수 있는 명령)
- 알려진 함정(느린 호출, 앱이 꺼져 있을 때의 동작, 설정 토글 위치)
- 검증 여부: 확인한 날짜·macOS 버전, 확인 못 한 건 `(미검증)`

## 담지 않는 것
- 개인 내용: 파일·메일·일정·메모의 실제 내용, 계정명, 폴더 구조, 사용자 이름이 든 경로
- 사용자의 선호·습관(그건 기억으로 간다)
- 시크릿·토큰

## 양식
```
# <앱 이름> (<번들 ID>)
- 스크립트: <예/아니오 + 근거>  - 권한: <자동화/손쉬운 사용/…>
## 빠른 방법
## 함정
## 검증: <날짜> macOS <버전>
```

## 현재 노트
- finder.md · safari.md · system-settings.md
